# Прошивка и загрузка программы

Здесь два разных действия, их часто путают:

| Что | Как часто | Что делает |
|---|---|---|
| **Прошивка платы** (`.uf2`) | один раз на новую плату | ставит MicroPython, умеющий работать с этим дисплеем |
| **Файлы программы** (6 `.py`) | при каждом изменении кода | собственно угломер |

Порядок: сначала прошивка, потом файлы.

---

## 1. Прошивка платы (MicroPython)

> ⚠️ Нужна **прошивка Waveshare**, не официальная с micropython.org.
> С официальной дисплей не заработает — экран останется чёрным.

Готовая прошивка уже лежит в репозитории:
`firmware/RPI_PICO-20260406-v1.28.0.uf2`

Если её нет — скачать: **https://www.waveshare.com/wiki/RP2040-LCD-1.28** →
раздел **Resources** → архив с примерами → папка **MicroPython** → файл `.uf2`.

### Шаги

1. Отключить плату от USB.
2. Зажать **BOOT** и, не отпуская, подключить USB-C.
3. Отпустить **BOOT**.
4. В «Моём компьютере» появится диск **RPI-RP2**.
5. Скопировать `.uf2` в корень этого диска.
6. Диск исчезнет сам — плата перезагрузилась и прошита.

Если плата уже подключена и зажатие BOOT не сработало:
зажать **BOOT + RESET**, отпустить **RESET**, затем **BOOT**.

---

## 2. Настройка Thonny

1. Установить Thonny: **https://thonny.org** → Windows.
2. **Инструменты → Параметры → Интерпретатор**.
3. Выбрать **MicroPython (Raspberry Pi Pico)**.
4. **Port** — новый COM-порт, появившийся после подключения платы
   (обычно COM3…COM6; если не знаете какой — отключите плату, посмотрите
   список, подключите, новый порт и есть ваша плата).
5. **OK**. Внизу должно появиться приглашение `>>>`.

---

## 3. Загрузка файлов программы

Нужны **6 файлов**, все — в корень платы, имена менять нельзя:

```
main.py
lcd_driver.py
imu_qmi8658.py
writer.py
courier20.py
boolpalette.py
```

### Вариант А — из архива (быстро)

Распаковать `dist/uglomer-board-files.zip` и залить все 6 файлов (см. ниже).

### Вариант Б — вручную

Для каждого файла:

1. **Файл → Открыть** → выбрать файл на компьютере.
2. **Файл → Сохранить как…**
3. Выбрать **Raspberry Pi Pico** (не «Этот компьютер»).
4. Имя оставить точно такое же.
5. **OK**. Повторить для всех шести.

### Проверка

**Вид → Файлы**. Справа (на плате) должны быть видны все 6 файлов.

---

## 4. Запуск

1. Открыть `main.py` **с платы**.
2. **F5** или зелёная кнопка ▶.
3. На экране появятся цифры угла и напряжение.

`main.py` запускается автоматически при подаче питания — после прошивки
и заливки файлов достаточно воткнуть USB или батарею.

---

## 5. Обновление только кода

Меняли `main.py`? Достаточно залить один файл:

**Файл → Открыть** → новый `main.py` → **Сохранить как → Raspberry Pi Pico** →
**OK** → **F5**.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| Нет диска RPI-RP2 | Другой USB-C кабель (многие только для зарядки). Драйвер: https://zadig.akeo.ie |
| Нет COM-порта в Thonny | Переподключить плату, нажать красный **Stop**, проверить порт |
| `>>>` не появляется | Красный **Stop**, затем переподключить USB |
| Экран чёрный после заливки | Не хватает файлов или имена не совпадают — должно быть ровно 6 |
| Программа зависла | **Stop** (Ctrl+C) в Thonny или кнопка **RESET** на плате |
| Экран белый / мусор | Прошивка не от Waveshare — перепрошить файлом из `firmware/` |

## Чек-лист «с нуля»

- [ ] Плата прошита `.uf2` из `firmware/`
- [ ] Thonny видит плату, есть `>>>`
- [ ] На плате 6 файлов, имена совпадают
- [ ] `main.py` запускается по F5
- [ ] Кнопка на GP0 обнуляет угол (`ZERO SET!`)
- [ ] После переподключения USB программа стартует сама
