# 📖 Полная инструкция: RP2040-LCD-1.28 + Thonny + Угломер

> Сохраните этот файл — здесь всё что нужно от покупки до загрузки программы.

---

## ЧТО НУЖНО ИМЕТЬ

- Плата **Waveshare RP2040-LCD-1.28**
- Кабель **USB-C** (обязательно с передачей данных, не только зарядный!)
- Компьютер с Windows 10/11
- Интернет (один раз — скачать Thonny и прошивку)
- Тактовая кнопка + 2 провода (для кнопки обнуления)

---

## ШАГ 1 — Скачать и установить Thonny

1. Открыть браузер, перейти на **https://thonny.org**
2. Нажать **"Windows"** — скачается файл `thonny-x.x.x.exe`
3. Запустить установщик, нажимать **"Next"** до конца
4. После установки **не запускайте** Thonny сразу — сначала прошивка

---

## ШАГ 2 — Прошить плату (MicroPython)

> Это делается **один раз** на новой плате. После этого повторять не нужно.
> Если плата уже прошита и работает — пропустите этот шаг.

### 2а. Скачать прошивку

Прошивка специальная — от Waveshare, не от официального MicroPython!

1. Перейти на страницу вики платы:
   **https://www.waveshare.com/wiki/RP2040-LCD-1.28**
2. Прокрутить вниз до раздела **"Resources"** → скачать архив с примерами
3. В архиве найти папку **MicroPython** → там будет файл с расширением **`.uf2`**
   (примерно: `rp2040_micropython_xxx.uf2`)

> ⚠️ Если использовать официальную прошивку с micropython.org — дисплей
> работать не будет. Нужна именно прошивка из пакета Waveshare.

### 2б. Войти в режим загрузчика (Bootloader)

На плате есть две маленькие кнопки рядом с USB-C разъёмом:
- **BOOT** — кнопка входа в режим прошивки
- **RESET** — кнопка перезагрузки

**Способ 1 (проще):**
1. Отключите плату от USB
2. Зажмите кнопку **BOOT** и держите
3. Подключите USB-C к компьютеру
4. Отпустите **BOOT**

**Способ 2 (если плата уже подключена):**
1. Зажмите **BOOT + RESET** одновременно
2. Отпустите сначала **RESET**, потом **BOOT**

**Результат:** На компьютере появится новый диск — **RPI-RP2**
(как флешка в "Моём компьютере")

### 2в. Скопировать прошивку

1. Открыть диск **RPI-RP2** в проводнике
2. Скопировать файл `.uf2` прямо в корень этого диска
3. Диск сам отключится — плата перезагрузится автоматически
4. Прошивка установлена ✓

## ШАГ 3 — Настроить Thonny

1. Запустить **Thonny**
2. В меню выбрать: **Инструменты → Параметры → Интерпретатор**
   (или Tools → Options → Interpreter)
3. В выпадающем списке выбрать:
   **"MicroPython (Raspberry Pi Pico)"**
4. В строке **Port** выбрать порт с платой:
   - Windows: обычно **COM3, COM4, COM5** (посмотрите какой появился новый)
   - Если не знаете какой — отключите плату, посмотрите список,
     подключите — новый порт и есть ваша плата
5. Нажать **OK**

### Проверка соединения

Внизу Thonny должна появиться надпись:
```
MicroPython vX.XX on 202X-XX-XX; Waveshare RP2040-LCD with RP2040
>>>
```
Мигающий курсор `>>>` — плата подключена и готова ✓

Если вместо этого ошибка — нажмите кнопку **Stop** (красный квадрат) вверху.

---

## ШАГ 4 — Загрузить файлы угломера на плату

Нужно загрузить **6 файлов** (все они от Waveshare + наш main.py):

| Файл | Что это |
|------|---------|
| `main.py` | **Главная программа угломера** (наш код) |
| `lcd_driver.py` | Драйвер дисплея |
| `imu_qmi8658.py` | Драйвер датчика IMU |
| `writer.py` | Вывод текста |
| `courier20.py` | Шрифт |
| `boolpalette.py` | Цвета для шрифта |

Файлы `lcd_driver.py`, `imu_qmi8658.py`, `writer.py`, `courier20.py`, `boolpalette.py`
берутся из архива Waveshare (папка MicroPython в скачанном пакете).
Файл `main.py` — наш угломер.

### Как загрузить каждый файл:

1. В Thonny: **Файл → Открыть** → выбрать файл на компьютере
2. Файл откроется в редакторе
3. **Файл → Сохранить как...**
4. Появится окно с выбором: **"Raspberry Pi Pico"** или **"Этот компьютер"**
5. Выбрать **"Raspberry Pi Pico"**
6. Имя файла оставить **точно такое же** (например `lcd_driver.py`)
7. Нажать **OK**
8. Повторить для всех 6 файлов

### Проверить что файлы на плате:

В Thonny: **Вид → Файлы** (View → Files)
Откроется панель — слева файлы компьютера, справа файлы на плате.
Должны быть видны все 6 файлов.

---

## ШАГ 5 — Запустить угломер

1. В Thonny открыть `main.py` (с платы)
2. Нажать **F5** или зелёную кнопку ▶ "Запустить"
3. На дисплее появятся цифры угла ✓

### Автозапуск при включении

Файл с именем `main.py` запускается **автоматически** при подаче питания —
как только подключите батарею или USB, программа стартует сама.
Ничего дополнительно настраивать не нужно.

---

## ШАГ 6 — Подключить кнопку обнуления

```
Плата                    Кнопка
─────                    ──────
GP0 (H1, пин №2)  ────► вывод 1
GND (H1, пин №20) ────► вывод 2
```

Резистор не нужен — он уже внутри чипа (PULL_UP в коде).
Нажать кнопку = обнулить угол в текущем положении.

## ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Плата не появляется в Thonny / нет COM-порта
- Попробуйте другой USB-C кабель (многие кабели только для зарядки!)
- Установить драйвер: **https://zadig.akeo.ie** → выбрать плату → Install Driver
- Перезагрузить компьютер

### Thonny пишет "не удаётся подключиться"
- Нажать красную кнопку **Stop** в Thonny
- Если не помогает: отключить и подключить плату
- Проверить что выбран правильный COM-порт

### Плата не реагирует на кнопки (завис main.py)
- В Thonny нажать **Stop** (Ctrl+C)
- Или зажать кнопку **RESET** на плате

### После загрузки файла экран чёрный
- Убедитесь что загружены ВСЕ 6 файлов
- Проверьте имена файлов — они должны совпадать точно

### Нужно обновить только main.py (поменяли код)
- Открыть новый `main.py` в Thonny
- Файл → Сохранить как → Raspberry Pi Pico → OK
- Старый файл перезапишется автоматически
- Нажать F5 для запуска
