# План развития

## Цель

Прошивка «воткнул USB — залил»: одна команда, без Thonny и без ручного
копирования шести файлов. И то же самое из opencode, чтобы правки кода
сразу проверялись на железе.

## Этап 0 — как сейчас (ручной)

- Прошивка `.uf2` копированием на диск `RPI-RP2`.
- 6 файлов заливаются вручную через Thonny.
- См. `docs/ПРОШИВКА.md`.

Минусы: 6 раз «Сохранить как», легко забыть файл, нет проверки результата.

## Этап 1 — скрипт заливки файлов

`tools/flash.py` (обёртка над `mpremote`):

1. Найти плату автоматически (`mpremote connect auto`, при необходимости
   по USB VID:PID `2E8A`).
2. Сравнить хеши файлов на плате и в репозитории — заливать только изменённые.
3. Скопировать 6 файлов в корень платы.
4. `soft-reset` и вывод первых строк с платы: если `main.py` упал, видно сразу.

Зависимость: `pip install mpremote` (нужен `pyserial` — уже стоит).

Почему `mpremote`, а не `rshell`/`ampy`: входит в проект MicroPython,
работает и на Windows, умеет `cp -r`, `mount`, `exec`, `soft-reset`.

## Этап 2 — прошивка `.uf2` без рук

`tools/firmware.py`:

1. Перевести плату в BOOT: через `mpremote` (`bootloader`) или
   подсказать зажать BOOT + переподключить.
2. Дождаться появления диска `RPI-RP2` (опрос раз в 200 мс, таймаут ~20 с).
3. Скопировать `firmware/*.uf2`.
4. Дождаться исчезновения диска = плата перепрошилась.

`picotool` не обязателен: копирование `.uf2` на диск работает всегда,
а `picotool` пришлось бы ставить отдельно.

## Этап 3 — из opencode

- Один скрипт `tools/flash.cmd` без аргументов: файлы + при `--fw` прошивка.
- В opencode: «залей на плату» → запуск скрипта, вывод ошибок с платы
  читается прямо в чат, правка кода и повтор без переключения окон.
- Проверка после заливки: читать `sys.print_exception` / первые строки
  вывода, а не «вроде залилось».

## Что понадобится

| Задача | Инструмент | Статус |
|---|---|---|
| Копирование файлов | `mpremote` | не установлен |
| Определение порта | `mpremote connect auto` / pyserial | `pyserial` есть |
| Прошивка `.uf2` | копирование на `RPI-RP2` | работает вручную |
| Перезапуск | `mpremote soft-reset` | — |

## Открытые вопросы

- Нужен ли режим «прошить только main.py» отдельной кнопкой — для быстрых правок.
- Держать `.uf2` в репозитории (660 КБ) или качать при первом запуске.
- Что делать, если плата занята Thonny (порт открыт) — закрывать или просить.
